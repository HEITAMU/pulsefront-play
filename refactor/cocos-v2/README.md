## 这一版怎么玩

- 主页点击炮台平滑入场；战斗中按下立即发射，按住持续射击；左右相对拖动瞄准，松手保留方向，再次按下不会跳转。
- 鼓点到达时点按，或完成一次明显的左右换向，发出金色冲击波；四次有效强拍获得超载。
- 第 18、38 秒暂停补给，三选一强化。每日挑战还有第 58 秒第三次补给。
- 普通关前两关 60 秒，其余 75 秒，共 100 关；首领在末段出现。需要守住防线并击破首领。星屑用于主炮、波峰范围和导弹弹芯成长。
- 每日挑战 90 秒，北京时间每天一局固定种子；统一初始属性、固定逻辑场地，不使用永久升级或广告复活。可以重复挑战取最高分。
- 分享包含当天、规则版本和目标分数；当天有效的分享链接进入后显示目标。微信开放数据域显示真实好友成绩，浏览器只显示个人成绩，不生成假排名。

## 音乐

统一 108 BPM、直拍 4/4。每个四分音符均有低鼓，2/4 拍有军鼓，贝斯保持律动。没有隐藏主鼓的长前奏，没有中途变速。
强拍判定窗口 ±120ms。判定和光圈共用音频时钟；支持浏览器输出时间戳时使用实际输出时间补偿。音乐短 PCM 音色在开战前分批缓存，战斗中只调度复用样本。活动声音最多 64 个；停止、暂停、切后台清理全部声音节点。

## 代码结构

| 文件 | 职责 |
|---|---|
| `assets/scripts/core/Combat.ts` | 不依赖引擎的固定步长战斗、种子、碰撞、局内进化 |
| `assets/scripts/core/Audio.ts`、`music.ts` | 稳定节拍、缓存音色、声音生命周期 |
| `assets/scripts/view/BattleView.ts` | 一次预分配的原生 Cocos 精灵与效果池 |
| `assets/scripts/Pulsefront.ts` | 页面流程、触摸、暂停、视图绑定 |
| `assets/scripts/platform/Progress.ts` | 迁移、成长、结算幂等 |
| `assets/scripts/platform/Rewarded.ts` | 微信激励视频、失败与取消处理 |
| `assets/scripts/platform/Social.ts` | 当日挑战参数、分享、真实好友分数 |

战斗池上限：敌人 64，弹体 192，冲击波 10，碎屑 96。关闭的战斗物体复用，视图节点不会随每局时间增加。HUD 数字最高每秒更新 10 次，音频调度有单次预算，长帧不会执行无上限补算。

## 打开与构建

用 Cocos Creator **3.8.8** 打开本目录，打开 `assets/Main.scene`。

```sh
npm ci
npm run typecheck
npm test
npm run build:trial
```

`build:trial` 复用仓库内已有的官方 3.8.8 引擎运行时，生成 `build/web-mobile` 与 `build/wechatgame`。它不是 Creator 编辑器的正式导出。微信试玩包可导入微信开发者工具；美术放在 `artwork` 分包。

正式编辑器构建（本次未执行）：

```sh
COCOS_CREATOR=/path/to/CocosCreator npm run build:web
COCOS_CREATOR=/path/to/CocosCreator npm run build:wechat
```

微信构建脚本会补入开放数据域并保留正式 AppID。Creator 构建与本次运行时试玩是两条明确标注的产物，不混称。

## 已验证及限制

使用 `@cocos/creator-types@3.8.8` 的严格 TypeScript 检查通过。33 项自动检查覆盖时区边界、同帧重复踩拍、不同帧率确定性、局内选择、广告完成/取消/错误、重复结算、复活后结算、旧存档迁移、首关无永久升级通关、连续 24 局对象池边界，以及重复点炮台、异步装填、入场中切后台、炮台连续变换、音频独立调度与定时器清理。后五项使用引擎/音频替身验证代码契约，不能作为真实渲染或声音验收。详细记录在 `docs/validation.json`。

此前测试浏览器无法创建 WebGL 上下文，因此**没有完成实际渲染、触控手感、声音试听或 GPU 帧率验收**。当前环境没有 Creator 编辑器，也没有执行微信开发者工具编译及 iOS/Android 真机广告播放。此版应先试玩验收，不能据此宣称所有卡顿已消除或正式微信发布已完成。
