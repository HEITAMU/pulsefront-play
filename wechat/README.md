# 脉冲防线 · 微信小游戏 1.8.2

这是微信原生 Canvas 小游戏工程，不是网页套壳。100关战斗、怪物、完整圆波、节拍判定、Funk/蓝调编曲与护盾沿用现有项目。

## 导入与上传

1. 解压后，在微信开发者工具选择「小游戏」→「导入项目」，选择本文件所在的 `wechat` 文件夹。
2. 本工程已配置 AppID `wx43da24c6ac1e5a12`，使用该小游戏的开发者账号登录。请勿把广告位 ID 填在 AppID 处。
3. 使用基础库 3.9.0 或更新版，开启 ES6 转换与增强编译。工程无需 npm 安装；`bundle.js` 已生成。
4. `config.js` 已填入微信后台创建的通关翻倍广告位 `adunit-34f3a0d585044563`。请用与广告位所属小游戏一致的 AppID 测试。广告请求无填充或失败时只保留基础奖励，不假发双倍。
5. 在开发者工具编译，再使用「预览」做真机验收，确认下列项目后点击「上传」。上传之后还需要在微信后台配置类目、资质、隐私说明并提交审核；上传不等于审核通过或已产生收入。

此工程已配置 AppID 和通关翻倍广告位 ID；尚未执行本次广告接入后的微信开发者工具编译、真机广告播放验证或微信后台审核。只有实际发布新代码后，已上架版本才会使用新的广告配置。

## 本版养成与广告

- 主炮仍为20级；每级 +6% 基础伤害，5/10/15/20级解锁波峰/强峰/叠浪/重峰。
- 达到5/10/15/20级累计消耗：300 / 3,200 / 13,200 / 44,800 星屑。
- 中间项目改为波峰扩幅，10级上限，每级波峰覆盖角度 +3%，主炮5级后生效。旧射速等级按1:1转换，已有升级和星屑不重置。
- 升级不会提高敌人血量。普通细波不获得扩幅，强拍波峰的可见范围与伤害范围一致。
- 通关基础奖励自动入账，包含击破回收。玩家主动点击观看广告，平台明确回调完整观看后，追加同等星屑，总额为基础奖励×2。
- 标价是真实基础数值，双倍是真实增加。不使用假奖励、假广告、自动弹广告或限制正常领取。失败仍获得击破回收，挑战奖励单独发放。
- 养成按双倍通关收入规划；不看广告可重复挑战已开放关卡积攒，速度更慢。后期需要重复挑战，不会在100关首次通关前轻易满级。
- 一个通关记录只能追加一次奖励；提前退出、加载失败、无广告均不发额外奖励。广告加载中锁定重复点击。

## 真机验收清单

- iOS/Android首次启动中文与按钮完整，微信右上胶囊不遮挡游戏操作。
- 点击开始可听到完整编曲；暂停/恢复的音乐节拍与发射判定同步。
- 长按仅细波；主炮5级后手动踩拍或左右摇摆顶点踩拍出现定向波峰；扩幅升级只拓宽波峰。
- 切后台/来电后暂停，返回需手动继续，不跳过战斗时间。
- 广告完整看完奖励恰好追加一次；提前关闭/无填充/断网不追加；基础奖励一直保留。
- 关卡结尾刷怪减少、停止刷新、留出清场与音乐淡出时间。
- 旧存档升级保留；在真机退出重进核对关卡、星屑、成长等级。

## 源码与重建

发布包包含可直接导入的工程。仓库 `scripts/build-wechat.mjs` 从共享模块生成 bundle，运行 `node scripts/build-wechat.mjs` 后重建。
源码入口 `src/main.mjs`，原生触控、界面和生命周期；`src/rewarded.mjs` 对接微信广告。
存档使用设备本地 `wx.setStorageSync`。当前没有云存档或服务端防作弊；换设备不会自动同步，不能把本地存档用作现金交易凭证。
